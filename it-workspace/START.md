# NR. IT Workspace — GitHub Pages

Wgraj zawartość tego folderu do repozytorium. Następnie Settings → Pages → Deploy from a branch → main → /(root).

Cztery projekty mają osobne adresy w ramach tej samej aplikacji:
- `#desk` — Support Desk
- `#monitor` — Service Monitor
- `#qa` — QA Lab
- `#assets` — Asset Manager

To interaktywne demo. Zmiany są przechowywane tylko w tej przeglądarce. Monitoring pokazuje dane przykładowe. QA wykonuje lokalne kontrole reguł; scenariusze manualne wymagają samodzielnego wykonania i zapisania dowodów. Logowanie i wspólna baza wymagają osobnej paczki serwerowej PHP/SQLite.

EN/PL i jasny/ciemny motyw przełączasz w górnym pasku. Reset danych demo jest dostępny w oknie przycisku logowania. Kody QR prowadzą do kart urządzeń; nowo dodane urządzenia demo istnieją tylko na urządzeniu, na którym je zapisano.
