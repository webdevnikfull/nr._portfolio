# Currency Studio and Text Studio

Live previews and GitHub repositories are connected in `workspace-projects.js` and `studio-repositories.js`.

| Project | Live preview | GitHub repository |
| --- | --- | --- |
| Currency Studio | https://webdevnikfull.github.io/nr._currency-converter/ | https://github.com/webdevnikfull/nr._currency-converter |
| Text Studio | https://webdevnikfull.github.io/nr._text-analyzer/ | https://github.com/webdevnikfull/nr._text-analyzer |

Upload the contents of each standalone project folder to the root of its matching GitHub repository. Upload the contents of `portfolio/` to the portfolio repository or hosting root. GitHub Pages can serve all three projects because they use static HTML, CSS and JavaScript. Currency Studio fetches reference rates from Frankfurter when connected.
