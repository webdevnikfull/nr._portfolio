# Portfolio + IT Workspace

This folder is the combined static portfolio package. Upload its contents to the domain's `public_html` folder so the portfolio stays at the domain root and the workspace opens at `/it-workspace/`.

The portfolio language control remains available in Polish, English and German. The embedded IT Workspace keeps its rounded language switch and theme button, with the same navy, ice and dark-theme visual language.

For GitHub Pages, publish this folder as the repository root. The embedded workspace is demo-ready and stores its local data in the browser. Server-only functions from the SEOHOST edition require the separate PHP/private package.
